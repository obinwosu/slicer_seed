KCL CISS Slicer review
=======================

Enter your name in the review window before saving.
Save overwrites each segment and adds your name to the filename.
When you finish, upload each edited case's segments folder and labels file.
Do not upload ciss.nii.gz. That file is the MRI.

See README.md for how to open a batch in 3D Slicer.
Do not run review_cases.py directly in a terminal.
